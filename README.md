# Museum Web Game

以地方文化、傳統生活與博物館敘事為主題的瀏覽器互動遊戲原型，支援桌面與行動裝置操作。

目前可直接遊玩兩個站點關卡，並保留章節劇情、問答、記憶翻牌、防禦與接物等系統，供後續整合正式展覽內容。

## 目前可用狀態

- 可選擇小朋友版或一般版；小朋友版提供注音字型與簡化引導。
- 關卡入口與兩個站點已換上博物館場景背景，並由阿嬤、阿公角色引導玩家。
- 關卡一「灶台生火」可依移動節奏加入柴火、控制火候並完成計分。
- 關卡二「擂茶料理」包含兩段玩法：
  - 從流動軌道依指定順序拖入食材，避開柴火與石頭，以研磨棒完成五圈研磨。
  - 拖入配菜後快速連點菜刀完成切料，最後顯示擂茶組合成果。
- 支援滑鼠、觸控操作、操作音效與 16:9 響應式遊戲畫面。
- 提供 Web App Manifest 與 Service Worker，可在支援的瀏覽器安裝為 PWA。

本專案仍屬可玩原型；部分角色、場景、故事與舊版小遊戲素材仍會持續整理或替換。

## 快速啟動

需求：Python 3 與現代瀏覽器。遊戲本身不需要安裝套件或執行建置程序。

```powershell
git clone https://github.com/JMW-168/Museum-Web-Game.git
cd Museum-Web-Game
python -m http.server 8765
```

接著開啟：

<http://localhost:8765/>

請務必在含有 `index.html` 的專案根目錄執行伺服器。如果瀏覽器顯示的是資料夾清單，代表伺服器從上一層目錄啟動；請停止伺服器、進入專案根目錄後重新執行指令。

首次載入需要網路連線取得 Swiper 與 ZingTouch 的 CDN 資源。主要遊戲圖片、音效、影片與字型則存放於 repo 內。

## 操作方式

1. 選擇小朋友版或一般版。
2. 點擊「進入市場」，可播放或跳過開場影片。
3. 從關卡入口選擇「灶台生火」或「擂茶料理」。
4. 使用滑鼠或觸控進行點擊、連點、畫圈與拖曳。

建議使用橫向畫面。瀏覽器通常會在第一次使用者操作後才允許播放音效。

## 主要功能

### 灶台生火

- 柴火會依背景音樂的鼓點流入灶台，播放進度同時作為節奏判定基準。
- 玩家需在柴火進入判定區時加入柴火。
- 火候過低、理想或過高時會顯示不同回饋。
- 添柴會播放木頭撞擊音；補水維持靜音，避免干擾音樂節奏。
- 支援補水、失誤提示與完成摘要。

### 擂茶料理

- 正確食材與干擾物會隨機混入流動軌道。
- 點擊食材只會高亮，拖曳後才會移動。
- 拖錯不扣分，物件只會無法放入加工區。
- 研磨棒維持固定方向並沿擂缽邊緣移動，完成五圈後累積綠色茶汁。
- 砧板、食材與菜刀使用獨立圖層；砧板保持不動，菜刀執行切料動畫。
- 研磨與切料分別提供摩擦聲和切菜聲，操作時可直接聽見回饋。
- 每段限時 60 秒；時間到會協助補完，避免流程卡住。

### 共用系統

- 章節式對話與選項。
- 一般版與小朋友版資料。
- 問答題庫、相簿與收藏系統。
- 記憶翻牌、防禦、付款、拖曳互動與接物等小遊戲模組。
- 資源預載、音效管理、錯誤記錄與場景切換。

## 專案結構

```text
.
├─ index.html                 # 遊戲入口與腳本載入順序
├─ style.css                  # 全站與主要場景樣式
├─ css/                       # 各小遊戲樣式
├─ js/
│  ├─ core/                   # 場景、對話、音效、載入與狀態系統
│  ├─ data/                   # 劇情、題庫與素材清單
│  └─ minigames/              # 各小遊戲模組
├─ assets/                    # 圖片、音效、影片、字型與圖示
├─ manifest.json              # PWA Manifest
└─ sw.js                      # Service Worker 與快取版本
```

## 驗證方式

目前沒有完整的自動化測試套件。修改後至少應完成以下檢查：

```powershell
node --check js/minigames/StationDemoGame.js
node --check js/data/minigameAssets.js
git diff --check
```

瀏覽器人工檢查建議包含：

- 首頁、模式選擇與關卡入口能正常切換。
- 關卡一可完成判定、火候控制與結算。
- 關卡二點擊只高亮，拖曳物件保持在最上層。
- 食材放入後顯示在擂缽或砧板上。
- 研磨、切料、倒數、自動補完與成果畫面均能完成。
- Console 沒有 JavaScript 錯誤或素材 404。

Service Worker 更新後若仍看到舊畫面，可使用 `Ctrl + Shift + R` 強制重新整理，或清除該網站的快取後再試。

## 資料與安全邊界

- 專案是純前端靜態網站，不需要後端、資料庫、帳號或 API Key。
- 遊戲不會上傳玩家輸入；執行狀態主要保留在目前頁面與瀏覽器快取中。
- PWA 會在瀏覽器端快取公開遊戲素材，以支援較穩定的再次載入。
- Repo 內的圖片、音效、影片與字型可能有各自授權條件；公開發布或替換素材前，請確認可使用範圍。

## GitHub Pages 設定

在 GitHub Repository 中開啟：

`Settings` → `Pages` → `Build and deployment`

設定如下：

- Source：`Deploy from a branch`
- Branch：`main`
- Folder：`/ (root)`

儲存後，GitHub Pages 會從 `main` 分支根目錄部署靜態網站。
