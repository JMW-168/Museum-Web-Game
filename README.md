# Museum Web Game

以地方文化、傳統生活與博物館敘事為主題的瀏覽器互動遊戲原型，支援桌面與行動裝置操作。

目前可分別遊玩四個站點，也可選擇「完整劇情體驗」，跟著阿嬤阿公依序走完四段故事（約 10 分鐘，中間有一個中場過場）。執行期只載入這幾個入口需要的程式與素材。

## 目前可用狀態

- 首頁可切換繁體中文與簡體中文（切換鈕位於「搭乘時光機／回到現實」下方），並記住選擇；選單、劇情、四站玩法、結果頁與紅粿祝福卡都會使用目前語言。
- 可選擇小朋友版或一般版；小朋友版提供注音字型與簡化引導。
- 首頁使用森美蘭客家文化博物館主視覺場景與金色標題（標題後有灰階襯底以維持對比），點擊「搭乘時光機」後會經過兩頁引導說明（土樓旁白、爺爺奶奶歡迎），再進入遊戲入口；沒有進場影片。引導兩頁與遊戲入口頁的左上角都有「返回首頁」。
- 四個站點均已接入正式博物館場景背景。
- 單獨遊玩任一站點時，會有阿嬤或阿公的打字機對話作為**進入引導**與**離開引導**：進入對話 → 「聚光燈式」操作提示 → 遊戲 → 離開對話 →「看看成果」→ 結果頁。粿印製作在進入對話後仍保留花紋介紹。
- 「聚光燈式」操作提示：畫面壓暗、逐一框亮該關最關鍵的兩個操作（附手指與說明框），按「開始」才正式進入遊戲；可用「略過說明」跳過，同一次遊玩再玩一次不會重複顯示。
- 關卡一「灶台生火」可依移動節奏加入柴火、控制火候並完成計分。
- 關卡二「擂茶料理」包含兩段玩法：
  - 從流動軌道依指定順序拖入食材，避開柴火與石頭，以研磨棒完成五圈研磨。
  - 拖入配菜後快速連點菜刀完成切料，最後顯示擂茶組合成果。
- 關卡三「搖籃哄睡」可跟隨左右導引累積穩定度，支援滑鼠、單指觸控與鍵盤操作；長時間未完成時會自動放寬判定，不設失敗。
- 關卡四「粿印製作」包含花紋介紹、上下拖曳配對、四面粿印棒選面與長按壓印；完成後可分享或下載紅粿祝福卡。
- 「完整劇情體驗」以阿嬤、阿公的打字機對話串接四個站點：灶台生火 →擂茶料理 →中場過場 →搖籃哄睡 →粿印製作與動態祝福結尾，銜接分享／下載祝福卡，最後接通關致謝畫面。前半段任一關結果皆可繼續，逾時關卡會自動補完；中途離開會失去整段進度。
- 劇情字卡逐字速度較慢，並在文字剛出現時短暫擋住連點，避免一次跳過整張內容。
- 支援滑鼠、觸控操作、操作音效與 16:9 響應式遊戲畫面。
- 提供 Web App Manifest 與 Service Worker，可在支援的瀏覽器安裝為 PWA。

本專案仍屬可玩原型。四個站點的正式場景背景與舊內容清理均已完成實作及使用者驗收；站點 3 的哭泣、漸靜與睡著三段音效目前仍為合成回饋音，正式授權素材待補。

## 快速啟動

需求：Python 3 與現代瀏覽器。遊戲本身不需要安裝套件或執行建置程序。

```powershell
git clone https://github.com/JMW-168/Museum-Web-Game.git
cd Museum-Web-Game
python -m http.server 8765
```

接著開啟：

<http://localhost:8765/>

請務必在含有 `index.html` 的專案根目錄執行伺服器。如果瀏覽器顯示的是資料夾清單，代表伺服器從上一層目錄啟動；請停止伺服器、進入專案根目錄後重新執行指令。

首次載入會連線取得 Google Fonts（介面字型為思源宋體 Noto Serif TC，切換簡體時再載入 Noto Serif SC，皆為 SIL Open Font License）；主要遊戲圖片、音效與注音字型皆存放於 repo 內。

## 操作方式

1. 選擇小朋友版或一般版。
2. 點擊「搭乘時光機」，看完兩頁引導說明後前往遊戲入口。
3. 在遊戲入口頁選擇四個站點單獨體驗，或選擇「完整劇情體驗」依序走完四段故事（約 10 分鐘）。
4. 單獨遊玩時：看完進入引導對話 → 聚光燈式操作提示（可按「略過說明」）→ 按「開始」進入遊戲 → 完成後看離開引導對話 → 結果頁。
5. 使用滑鼠或觸控進行點擊、連點、畫圈與拖曳。

建議使用橫向畫面。瀏覽器通常會在第一次使用者操作後才允許播放音效。

## 主要功能

### 灶台生火

- 灶台、火焰與柴火採手繪繪本式數位厚塗風格；人物立繪與背景維持原設計。
- 柴火會依背景音樂的鼓點流入灶台，播放進度同時作為節奏判定基準。
- 玩家需在柴火進入判定區時加入柴火。
- 高對比火候條會標示安全控火區，火候過低、理想或過高時會顯示不同回饋。
- 添柴會播放木頭撞擊音；補水維持靜音，避免干擾音樂節奏。
- 單玩結束時先顯示分數與阿罵評語，再選擇「再玩一次」或「去找阿罵」進入離開對話。

### 擂茶料理

- 正確食材與干擾物會隨機混入流動軌道。
- 點擊食材只會高亮，拖曳後才會移動。
- 拖錯不扣分，物件只會無法放入加工區。
- 擂缽、研磨棒、菜刀、食材與配菜為手繪風格圖片素材。
- 研磨棒維持固定方向，杵尖沿擂缽內緣畫圓，每種食材完成五圈；研磨進度以擂缽狀態圖呈現。
- 砧板、食材與菜刀使用獨立圖層並各自維持原比例；砧板保持不動，菜刀執行切料動畫。
- 配菜每種快速連點六刀完成，切好的配菜會逐一顯示在旁邊。
- 研磨與切料分別提供摩擦聲和切菜聲，操作時可直接聽見回饋。
- 每段限時 60 秒；時間到會協助補完，避免流程卡住。

### 完整劇情體驗

- 遊戲入口頁的單一入口（副標「約 10 分鐘」），依序串接四個站點的劇情與玩法。
- 以人物置中、底部字幕框與逐字顯示的對話形式呈現開場、關間與結尾劇情；逐字速度較慢，文字剛出現時的短時間內連點不會一次跳過整張字卡。
- 前半段：阿嬤引導完成灶台生火，關後前往阿公的擂茶料理；成功或失敗皆能繼續，逾時會自動補完。
- 中場過場：上半場結束後顯示「繼續下半場」，玩家按下才進入後半段。
- 後半段：阿嬤聽見哭聲帶入搖籃哄睡，回到廚房製作紅粿；結尾依玩家選擇的花紋帶入名稱、寓意與祝福，再顯示可分享或下載的祝福卡，最後接通關致謝畫面並返回入口。
- 中途離開會清除目前狀態並返回入口，不殘留計時器或事件監聽；由於是連續體驗，離開後整段進度不保留。
- 四個站點仍可從各自的入口單獨遊玩，各自帶有進入／離開引導對話。

### 搖籃哄睡

- 上方光點以約 2.4 秒為一個左右循環，引導玩家搖動搖籃。
- 玩家操作並跟上導引時累積穩定度，偏離只會緩慢回退，不會歸零。
- 25 秒仍未完成時會放寬跟隨範圍，避免體驗卡關。
- 支援滑鼠拖曳、單指觸控與鍵盤左右方向鍵。
- 完成或離開時會停止動畫與聲音並移除輸入監聽。
- 目前使用正式博物館場景背景與合成回饋音；哭泣、漸靜與睡著三段正式授權音效仍待替換。

### 粿印製作

- 先認識龜紋、桃紋、魚紋與連錢紋的祝福寓意。
- 將花紋卡拖到正確的寓意卡；整張卡片都是有效拖曳區域，接近目標時會自動吸附。
- 選擇花紋後，依提示移動米糰、旋轉四面粿印棒、對準中央並長按完成壓印。
- 完成畫面會呈現紅粿與祝福文字，並可使用系統分享功能或下載 1080×1350 PNG 祝福卡。

### 共用系統

- 繁體／簡體中文全流程切換（首頁選擇、記住偏好，涵蓋劇情、玩法、結果頁與祝福卡，並依語言切換字型）。
- 一般版與小朋友版模式選擇。
- 完整劇情體驗保留逐字劇情效果，不依賴舊對話系統。
- 四關共用的「聚光燈式」進入操作提示元件（壓暗畫面、框亮目標元素、手指與說明框）。
- 資源載入、音效管理、錯誤記錄與場景切換。
- Web App Manifest、Service Worker 與安裝提示。

```text

│  ├─ core/                   # 場景、音效、載入與錯誤記錄

└─ sw.js                      # Service Worker 與快取版本
```

## 驗證方式

目前沒有完整的自動化測試套件。修改後至少應完成以下檢查：

```powershell
node --check js/minigames/StationIntroGuide.js
node --check js/minigames/StationDemoGame.js
node --check js/minigames/CradleStationGame.js
node --check js/minigames/CakeStationGame.js
node --check js/minigames/Station34CombinedGame.js
node --check js/minigames/EndingScreen.js
node --check js/main.js
node --check js/i18n/i18n.js
node scripts/test-combined34-hooks.js
node scripts/test-i18n.js
git diff --check
```

瀏覽器人工檢查建議包含：

- 首頁可切換繁體／簡體（切換鈕在兩個主按鈕下方），重新整理後記住選擇；切簡體時字型換為 Noto Serif SC，劇情、四站玩法、結果頁與祝福卡均使用簡體。
- 首頁底圖、標題與襯底、主按鈕與語言切換鈕在 710×407 與 1280×720 皆不裁切、不溢出；繁／簡兩語文字不溢出。
- 新封面、模式選擇與遊戲入口頁能正常切換；「搭乘時光機」→ 兩頁引導說明 → 遊戲入口，不經影片；引導兩頁與遊戲入口頁的「返回首頁」都會回到首頁。
- 遊戲入口頁顯示副標「請根據您的所在位置挑選您的站點」、四張站點卡（站點 1～4）與一張「完整劇情體驗」卡；繁／簡兩語不溢出。
- 單獨遊玩四關任一關：進入引導對話（阿嬤／阿公打字機）→ 聚光燈式操作提示（逐步框亮兩個操作，按「開始」後計時／動畫／背景音樂才啟動；「略過說明」可跳過）→ 遊戲 → 離開引導對話 → 結果頁。再玩一次不重播進入對話。
- 關卡一可完成判定、火候控制與結算。
- 關卡二點擊只高亮，拖曳物件保持在最上層。
- 食材放入後顯示在擂缽或砧板上。
- 研磨、切料、倒數、自動補完與成果畫面均能完成。
- 搖籃未操作時不累積進度，滑鼠／觸控／鍵盤可操作，25 秒後輔助正常且能完成結算。
- 粿印可完成上下配對、選面、移動、長按壓印，以及分享／下載祝福卡。
- 完整劇情體驗可依序完成開場、灶台生火、關後劇情、擂茶料理、中場過場（繼續下半場）、搖籃哄睡、粿印、動態花紋結尾、祝福卡與通關致謝畫面，最後返回入口；中途離開可正常返回入口。
- 劇情字卡完整出現後，短時間內快速連點不會一次跳過多張字卡。
- 710×407 與 1280×720 畫面不裁切人物、字幕或主要按鈕。
- Console 沒有 JavaScript 錯誤或素材 404。

Service Worker 更新後若仍看到舊畫面，可使用 `Ctrl + Shift + R` 強制重新整理，或清除該網站的快取後再試。

## 資料與安全邊界

- 專案是純前端靜態網站，不需要後端、資料庫、帳號或 API Key。
- 遊戲不會上傳玩家輸入；執行狀態主要保留在目前頁面與瀏覽器快取中。
- PWA 會在瀏覽器端快取公開遊戲素材，以支援較穩定的再次載入。
- Repo 內的圖片、音效與字型可能有各自授權條件；公開發布或替換素材前，請確認可使用範圍。

## GitHub Pages 設定

在 GitHub Repository 中開啟：

`Settings` → `Pages` → `Build and deployment`

設定如下：

- Source：`Deploy from a branch`
- Branch：`main`
- Folder：`/ (root)`

儲存後，GitHub Pages 會從 `main` 分支根目錄部署靜態網站。
