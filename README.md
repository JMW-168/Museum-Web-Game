# Museum Web Game

以地方文化、傳統生活與博物館敘事為主題的瀏覽器互動遊戲原型，支援桌面與行動裝置操作。

目前可分別遊玩四個站點關卡，也可從「關卡一二合併版」或「三四關合併版」依序體驗兩段劇情；專案另保留章節劇情、問答、記憶翻牌、防禦與接物等系統，供後續整合正式展覽內容。

## 目前可用狀態

- 可選擇小朋友版或一般版；小朋友版提供注音字型與簡化引導。
- 首頁使用森美蘭客家文化博物館主視覺與動態標題，點擊「搭乘時光機」後直接進入遊戲入口，不再播放進場影片。
- 關卡入口與前兩個站點已換上博物館場景背景，並由阿嬤、阿公角色引導玩家。
- 關卡一「灶台生火」可依移動節奏加入柴火、控制火候並完成計分。
- 關卡二「擂茶料理」包含兩段玩法：
  - 從流動軌道依指定順序拖入食材，避開柴火與石頭，以研磨棒完成五圈研磨。
  - 拖入配菜後快速連點菜刀完成切料，最後顯示擂茶組合成果。
- 關卡三「搖籃哄睡」可跟隨左右導引累積穩定度，支援滑鼠、單指觸控與鍵盤操作；長時間未完成時會自動放寬判定，不設失敗。
- 關卡四「粿印製作」包含花紋介紹、上下拖曳配對、四面粿印棒選面與長按壓印；完成後可分享或下載紅粿祝福卡。
- 「關卡一二合併版」以阿嬤、阿公的打字機對話串接生火與擂茶；第一關無論結果皆可繼續，第二關逾時也會自動補完。
- 「三四關合併版」從嬰孩哭聲帶入搖籃哄睡，回到廚房完成粿印與動態祝福結尾，最後銜接分享／下載祝福卡。
- 支援滑鼠、觸控操作、操作音效與 16:9 響應式遊戲畫面。
- 提供 Web App Manifest 與 Service Worker，可在支援的瀏覽器安裝為 PWA。

本專案仍屬可玩原型；部分角色、場景、故事與舊版小遊戲素材仍會持續整理或替換。

## 快速啟動

需求：Python 3 與現代瀏覽器。遊戲本身不需要安裝套件或執行建置程序。

```powershell
git clone https://github.com/JMW-168/Museum-Web-Game.git
cd Museum-Web-Game
python -m http.server 8765
```

接著開啟：

<http://localhost:8765/>

請務必在含有 `index.html` 的專案根目錄執行伺服器。如果瀏覽器顯示的是資料夾清單，代表伺服器從上一層目錄啟動；請停止伺服器、進入專案根目錄後重新執行指令。

首次載入需要網路連線取得 Swiper 與 ZingTouch 的 CDN 資源。主要遊戲圖片、音效與字型則存放於 repo 內。

## 操作方式

1. 選擇小朋友版或一般版。
2. 點擊「搭乘時光機」，直接前往遊戲入口。
3. 從關卡入口選擇四個獨立站點，或選擇「關卡一二合併版」及「三四關合併版」。
4. 使用滑鼠或觸控進行點擊、連點、畫圈與拖曳。

建議使用橫向畫面。瀏覽器通常會在第一次使用者操作後才允許播放音效。

## 主要功能

### 灶台生火

- 柴火會依背景音樂的鼓點流入灶台，播放進度同時作為節奏判定基準。
- 玩家需在柴火進入判定區時加入柴火。
- 火候過低、理想或過高時會顯示不同回饋。
- 添柴會播放木頭撞擊音；補水維持靜音，避免干擾音樂節奏。
- 支援補水、失誤提示與完成摘要。

### 擂茶料理

- 正確食材與干擾物會隨機混入流動軌道。
- 點擊食材只會高亮，拖曳後才會移動。
- 拖錯不扣分，物件只會無法放入加工區。
- 研磨棒維持固定方向並沿擂缽邊緣移動，完成五圈後累積綠色茶汁。
- 砧板、食材與菜刀使用獨立圖層；砧板保持不動，菜刀執行切料動畫。
- 研磨與切料分別提供摩擦聲和切菜聲，操作時可直接聽見回饋。
- 每段限時 60 秒；時間到會協助補完，避免流程卡住。

### 關卡一二合併版

- 以人物置中、底部字幕框與逐字顯示的對話形式呈現開場、關間與結尾劇情。
- 阿嬤引導玩家完成灶台生火，關後可直接前往阿公的擂茶料理。
- 第一關成功或失敗皆能繼續；第二關兩段逾時時會自動補完。
- 結尾可返回入口大廳，原本兩個獨立關卡入口不受影響。

### 三四關合併版

- 以阿嬤聽見哭聲開場，先帶玩家完成搖籃哄睡，再回到廚房製作紅粿。
- 第三關完成後會自動銜接關間劇情與第四關，兩個獨立入口仍可分別遊玩。
- 結尾依玩家選擇的花紋帶入名稱、寓意與祝福，再顯示可分享或下載的祝福卡。
- 中途離開會清除目前關卡與劇情狀態並返回入口，不殘留計時器或事件監聽。

### 搖籃哄睡

- 上方光點以約 2.4 秒為一個左右循環，引導玩家搖動搖籃。
- 玩家操作並跟上導引時累積穩定度，偏離只會緩慢回退，不會歸零。
- 25 秒仍未完成時會放寬跟隨範圍，避免體驗卡關。
- 支援滑鼠拖曳、單指觸控與鍵盤左右方向鍵。
- 完成或離開時會停止動畫與聲音並移除輸入監聽。
- 目前使用程式繪製的暫用場景與合成回饋音；正式背景及授權音效仍待替換。

### 粿印製作

- 先認識龜紋、桃紋、魚紋與連錢紋的祝福寓意。
- 將花紋卡拖到正確的寓意卡；整張卡片都是有效拖曳區域，接近目標時會自動吸附。
- 選擇花紋後，依提示移動米糰、旋轉四面粿印棒、對準中央並長按完成壓印。
- 完成畫面會呈現紅粿與祝福文字，並可使用系統分享功能或下載 1080×1350 PNG 祝福卡。

### 共用系統

- 章節式對話與選項。
- 一般版與小朋友版資料。
- 問答題庫、相簿與收藏系統。
- 記憶翻牌、防禦、付款、拖曳互動與接物等小遊戲模組。
- 資源預載、音效管理、錯誤記錄與場景切換。

## 驗證方式

目前沒有完整的自動化測試套件。修改後至少應完成以下檢查：

```powershell
node --check js/minigames/StationDemoGame.js
node --check js/minigames/CradleStationGame.js
node --check js/minigames/CakeStationGame.js
node --check js/minigames/Station34CombinedGame.js
node --check js/data/minigameAssets.js
node scripts/test-combined34-hooks.js
git diff --check
```

瀏覽器人工檢查建議包含：

- 新封面、模式選擇與關卡入口能正常切換；「搭乘時光機」不經影片直接顯示入口。
- 關卡一可完成判定、火候控制與結算。
- 關卡二點擊只高亮，拖曳物件保持在最上層。
- 食材放入後顯示在擂缽或砧板上。
- 研磨、切料、倒數、自動補完與成果畫面均能完成。
- 搖籃未操作時不累積進度，滑鼠／觸控／鍵盤可操作，25 秒後輔助正常且能完成結算。
- 粿印可完成上下配對、選面、移動、長按壓印，以及分享／下載祝福卡。
- 關卡一二合併版可依序完成開場、第一關、關後劇情、第二關、結尾與返回大廳。
- 三四關合併版可從開場進入搖籃，銜接粿印、動態花紋結尾與祝福卡；中途離開可正常返回入口。
- 710×407 與 1280×720 畫面不裁切人物、字幕或主要按鈕。
- Console 沒有 JavaScript 錯誤或素材 404。

Service Worker 更新後若仍看到舊畫面，可使用 `Ctrl + Shift + R` 強制重新整理，或清除該網站的快取後再試。

## 資料與安全邊界

- 專案是純前端靜態網站，不需要後端、資料庫、帳號或 API Key。
- 遊戲不會上傳玩家輸入；執行狀態主要保留在目前頁面與瀏覽器快取中。
- PWA 會在瀏覽器端快取公開遊戲素材，以支援較穩定的再次載入。
- Repo 內的圖片、音效與字型可能有各自授權條件；公開發布或替換素材前，請確認可使用範圍。

## GitHub Pages 設定

在 GitHub Repository 中開啟：

`Settings` → `Pages` → `Build and deployment`

設定如下：

- Source：`Deploy from a branch`
- Branch：`main`
- Folder：`/ (root)`

儲存後，GitHub Pages 會從 `main` 分支根目錄部署靜態網站。
